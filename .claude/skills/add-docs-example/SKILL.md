# Docs examples

- The docs app (`docs-app/`, run `npm run dev` → http://localhost:5180) auto-discovers `src/components/*/*.examples.tsx` via `import.meta.glob`.
- Export `examples: { title; description?; code; render }[]` — `code` is the snippet shown in the Code tab; `render` is the live preview.
- The component page shows spec purpose/status from `docs-app/src/catalog.generated.json` (generated by design-system-mcp `npm run sync:ui-kit` — never edit by hand).
- Cover: basic, variants/sizes, states, and one realistic scenario for a target profile.
- Verify in the browser in light + dark and with the profile switcher (top bar), then `npm run build:docs`.
